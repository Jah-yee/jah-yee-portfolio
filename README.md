# Jah-yee Portfolio

A cold, precision developer portfolio — terminal brutalism meets engineering dashboard.

**Stack:** Next.js 14 · Tailwind CSS · TypeScript · Vercel

## Development

```bash
npm install
npm run dev
```

## Design

Dark void aesthetic (#0a0a0a) with electric mint accents (#00ff88). JetBrains Mono typography. Every pixel earns its place.

See [SPEC.md](./SPEC.md) for full design specification.
